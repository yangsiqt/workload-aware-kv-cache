# Adaptive KV V2.3 — Primary Trace

Result scope: `PRIMARY_TRACE_REAL_4XH20_COHORT30_HOTSET`

## Experimental contract

- Hardware: 4 × NVIDIA H20 96GB, four TP1 vLLM backends.
- Model: Qwen3-30B-A3B-Instruct-2507.
- Backend concurrency: `max_num_seqs=12`.
- Cache per backend: 8 GiB LMCache CPU L1 and 24 GiB Mooncake L2.
- Workload: 200 SWE-bench-derived sessions × six turns = 1200 requests.
- Arrival: alternating 3.5/1.5 RPS, average 2.5 RPS.
- Client concurrency: 64.
- Before: `fixed-4096`.
- After: Adaptive KV V2.3 with a frozen 750 ms / 20% override guard.
- Both runs completed 1200/1200 requests with complete joined traces.

This public report contains the pre-registered primary trace only and does not
make a cross-trace stability claim.

## Mechanism evidence

- Adaptive overrides: 409.
- KV path changes: 409.
- Controller refresh failures: 0.
- HBM KV-event coverage: 100%.
- All four backends reported remaining decode work, router-side reserved decode
  tokens, decode backlog, and backend decode-throughput EWMA.
- The overrides primarily avoided uncertain or expensive external retrieval in
  favor of verified HBM reuse or recomputation. The result is not attributed to
  a higher L1/L2 hit rate.
